# Gate evaluation on the UR5e (2026-10-16)

Script: `code/vgap_gate_eval_ur5e.py`. Same motion and prompts as `vgap_trials_ur5e.py`, but it tests a fixed tau_c instead of picking one.
Each angle runs all orientations flat, then again propped on a screw (--placements flat,propped; default both). The operator grades each distinct pose per view (y correct / b a bit off / n wrong). Bursts then get an outcome: TA, FA (wrong pose let through), AO, TR, FR (good pose thrown away), RO.
Report tests: A confusion with 95% Wilson CIs, B rejections by reason, C accuracy of accepted poses, D gate on vs off, E adversarial injected poses, F proposed 3D check (within_3mm threshold sweep), G stress conditions (occluded, distractor, offcenter, partial, dim), H recovery move (--retry), I gripper-tip point check (--point-check, ruler), J class + runtime.
Combine runs: `--report data/gate_eval/*/`.
Sim check (L grey, 2 angles x 4 orientations x 3 bursts): 24/24 TA. Adversarial: C rejected all in-plane wrong poses but only 0% of raw 15 mm depth shifts and 38% of raw 15 deg tilts. Adding within_3mm >= 0.7 caught every wrong pose and lost no correct ones. Point check (sim) 1.5 mm horizontal.
Not run on hardware.
